# モーション(VMD)一覧

アプリで実際に使用するVMDモーションファイルをここに一元管理する。各ファイルの詳細(BPM等)は
[`apps/viewer/src/motions.ts`](../../src/motions.ts) を参照。

## ライセンス

| ファイル | ライセンス |
|---|---|
| `Helltaker_like_dance_1min_1.vmd` | CC0 1.0 Universal(パブリックドメイン) |
| `Helltaker_like_dance_1min_2.vmd` | CC0 1.0 Universal(パブリックドメイン) |
| `pose-capture.vmd` | 利用許可取得済み |

Helltaker系2ファイルの原本ライセンス文面: https://creativecommons.org/publicdomain/zero/1.0/deed.ja

`pose-capture.vmd` は当初出典不明のテスト用ファイルだったが、利用許可を得たため本フォルダに統合した。
