## 利用条件

**このMMDは非営利目的の利用に限り、この作品を改変しない利用に限られます。**

配布元(`Readme.txt` 参照)が定める利用規約は以下の通りです。

- 改造・再配布不可(スフィアマップ・エフェクト用の改変は可)
- このモデルの一部を別モデルへ移植すること不可
- 商用利用不可
- グロテスク表現を含むR-18コンテンツでの使用不可
- 政治的・宗教的・暴力的表現での使用不可

本プロジェクト(マジカルミライ プログラミング・コンテスト向けハッカソン制作物)では、上記条件を満たす**非営利・非改変**の範囲でのみこのモデルを使用します。ライブ視聴画面のステージ演出における仮設置(プレースホルダー)としての表示が用途です。

## ファイル構成

- `piloula-miku-expo10th.pmx` — モデル本体(標準版)
- `piloula-miku-expo10th-sune-ik.pmx` — モデル本体(すねIK付き版。配布元オリジナルファイル名は日本語+スペース混じりだったため、URL解決を安定させる目的でアプリ側ではこちらの標準版のみを読み込んでいます)
- `tex/`, `spa/`, `toon/` — モデルが参照するテクスチャ・スフィアマップ・トゥーンシェーディング用画像
- `Readme.txt` — 配布元オリジナルの利用規約(原文ママ)

不要だった配布物内のプレビュー画像(`miku expo.png`)や未参照のスフィアマップ(`spa/2.png`)は、アプリで実際に読み込まれないため削除済みです。
